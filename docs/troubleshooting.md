# 밋그린 트러블슈팅

밋그린을 만들고 스토어에 올리면서 막혔던 일을 **문제 → 원인 → 해결** 순서로 정리했어요. 포트폴리오: [cr-kstar.github.io/diet_project](https://cr-kstar.github.io/diet_project/)

## 1. App Store 반려 — Apple 로그인 오류 (2.1)

- **문제**: 심사에서 Apple 로그인이 동작하지 않는다며 반려됐어요.
- **원인**: Firebase 쪽 Apple 제공자 서버 설정(서비스 ID, 키)이 빠져 있었어요. 앱 코드는 문제가 없었어요.
- **해결**: 서비스 ID와 키를 설정하고, 계정을 삭제할 때 Apple 토큰도 철회하도록 구현해서 다시 제출했어요. 승인됐어요.

## 2. App Store 반려 — 건강 정보 출처 (1.4.1)

- **문제**: 칼로리 · 영양소 같은 건강 수치를 보여 주는데 근거가 없다는 이유로 반려됐어요.
- **원인**: 권장 칼로리를 어떤 식으로 계산하는지, 무엇을 참고했는지 사용자에게 알려 주지 않았어요.
- **해결**: 계산 방법과 참고 출처를 정리한 안내 문서([/sources/](https://cr-kstar.github.io/diet_project/sources/))를 만들고, 앱에서 볼 수 있게 연결해 재제출했어요.

## 3. 계정을 지워도 친구 · 챌린지 · 활동 기록이 남던 문제

- **문제**: 계정 삭제 뒤에도 다른 사람과 이어진 데이터가 남아 있었어요.
- **원인**: 내 기록만 지우고, 친구 · 챌린지 · 활동 피드처럼 사용자 사이에 걸쳐 있는 데이터는 삭제 대상에서 빠져 있었어요.
- **해결**: 저장소에 삭제 기능을 추가하고, 보안 규칙도 본인 것은 지울 수 있게 고치고, 개인정보 처리방침 문구도 함께 맞췄어요. 저장소 · 규칙 · 문구가 따로 놀지 않게 한 번에 고치는 게 중요했어요.

## 4. 한 번에 처리할 수 있는 개수 한도

- **문제**: 기록이 많은 계정을 지우거나 친구 목록을 조회할 때 Firestore의 개수 한도에 걸렸어요.
- **원인**: 한 번의 쓰기(배치)에 담을 수 있는 문서 수와, `whereIn` 조회에 넣을 수 있는 값의 수가 정해져 있어요.
- **해결**: 삭제는 300개씩 나눠서 지우고, `whereIn`은 30개씩 나눠서 조회했어요.

## 5. 로그아웃 뒤에도 이전 계정의 값이 남던 문제

- **문제**: 로그아웃하고 다른 계정으로 들어가면 약관 동의 · 공개 범위 같은 값이 그대로 남아 있었어요.
- **원인**: 로그아웃할 때 메모리에 있던 사용자 설정을 초기 상태로 돌리지 않았어요. 다음 계정이 앞 사람의 민감 정보 동의를 물려받는 셈이었어요.
- **해결**: 로그아웃할 때 초기 상태로 되돌리도록 고쳤어요.

## 6. 모든 사진 기록에 "확인 필요"가 붙던 문제

- **문제**: AI가 확신을 가지고 분석한 식단에도 "확인 필요" 표시가 붙었어요.
- **원인**: 기록을 저장할 때 이 값이 `true`로 고정되어 있었어요.
- **해결**: AI가 알려 주는 확신도에 따라 표시하고, 사용자가 "맞아요"를 누르면 표시가 사라지게 했어요. 고치기만 하는 게 아니라 확인했다고 알릴 수 있게 한 거예요.

## 7. "기록 전체 삭제" 버튼이 실제로는 지우지 않던 문제

- **문제**: 버튼을 누르면 안내 메시지만 뜨고 기록은 그대로였어요.
- **원인**: 화면에 메시지를 띄우는 코드만 있고, 실제 삭제는 연결되어 있지 않았어요.
- **해결**: 서버의 식단 · 운동 · 체중 · 물 기록을 지우고, 서버 삭제가 성공했을 때만 기기에 있는 기록과 사진도 정리하게 했어요. 서버 삭제가 실패하면 기기 쪽은 그대로 두고, 다시 누르면 이어서 지워요.

## 8. iOS 빌드를 내보낼 때마다 실패하던 문제

- **문제**: `flutter build ipa`가 마지막 내보내기 단계에서 매번 실패했어요.
- **원인**: Sign in with Apple이 들어간 프로비저닝 프로파일을 자동 내보내기가 고르지 못했어요.
- **해결**: 아카이브는 Flutter로 만들고, 내보내기는 `xcodebuild -exportArchive`와 프로파일을 지정한 `ExportOptions.plist`로 직접 했어요.

## 9. 새 빌드를 올려도 App Store에서 받아 주지 않던 문제

- **문제**: 빌드 번호만 올려서 다시 올렸더니 이미 닫힌 버전이라며 거절됐어요.
- **원인**: 1.0.0이 심사에 들어간 뒤에는 같은 버전 번호로 새 빌드를 올릴 수 없어요.
- **해결**: 버전 자체를 올려서(1.0.1) 다시 제출했어요. 빌드 번호는 스토어마다 따로 올라가야 한다는 것도 이때 정리했어요.

## 10. 웹 앱에서 Google 로그인이 안 되던 문제

- **문제**: 웹 앱을 배포했는데 Google 로그인이 되지 않았어요.
- **원인**: 새로 만든 웹 앱 주소가 Firebase 인증의 승인된 도메인에 없었어요.
- **해결**: 승인된 도메인에 주소를 추가하자 로그인됐어요. 웹에서는 팝업 방식으로 로그인해요.
