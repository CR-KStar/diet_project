Claude Code와 협업해 개발했고, 기획 방향과 검증, 아키텍처 구조 분리(ViewModel·Repository), 스토어 배포, 심사 대응은 직접 진행했어요. 아키텍처는 지금도 공부하며 한 단계씩 분리하고 있어요. 앱 아이콘 캐릭터는 AI로 생성했어요.

8개컬렉션별 보안 규칙 (내 기록 + 공유 7)

01스토어 제출과 심사 대응

  • iOS 서명 · TestFlight · App Privacy, Play 데이터 보안 · 개인 계정 비공개 테스트(12명, 14일)
  • 반려 2건(건강 정보 출처 1.4.1, Apple 로그인 2.1)을 원인 분석 후 수정, 재제출

02Firestore 모델링과 보안 규칙

  • 내 기록은 users/{uid} 하위, 함께 쓰는 데이터는 최상위로 분리
  • 컬렉션별 규칙(예: 친구 요청은 보낸 사람만 생성 · 받은 사람만 수락), 날짜를 정렬 가능한 키로 저장
  • 한도 대응: 삭제 300개씩, whereIn 30개씩

03서버리스 AI 파이프라인

  • 사진을 서버 함수로 보내 Claude가 음식 · 칼로리 · 영양소를 정해진 JSON으로 반환
  • API 키는 서버 Secret에만 보관, 한국어 이름 지시를 프롬프트와 스키마 양쪽에 반영
  • 외부 전송 전 사용자 동의 팝업

04계정 수명주기와 데이터 삭제

  • Apple 로그인 nonce(SHA-256), 삭제 순서: 재인증 → 토큰 철회 → 데이터 삭제 → 계정 삭제
  • 빠뜨린 소셜 데이터를 찾아 저장소 · 보안 규칙 · 처방침 문구를 함께 수정하고 테스트로 보호

05Repository 추상화와 테스트 구조 분리 진행 중

  • 저장소 인터페이스에 Firestore · 메모리 두 구현 → 서버 없이 테스트 · 웹 데모
  • 시계 주입으로 날짜를 고정하는 테스트, 3,400줄 상태 클래스를 영역별 ViewModel로 분리 중

06사용자 경험의 세부 완성도

  • 기록 여부에 따라 바뀌는 동적 앱 아이콘(iOS 대체 아이콘 · Android activity-alias)
  • 글자 크기 배율 · 디자인 토큰 · 화면 오버플로 점검, 로그인 없는 웹 체험판
