# 다이어트 관리 앱

사진 한 장으로 끝나는 식단 기록과, 기록이 식물로 자라는 보상 루프를 결합한 다이어트 관리 앱입니다.  
HTML 단일 파일 프로토타입으로 동작하며, 별도 설치 없이 브라우저에서 바로 열립니다.

## 배경

기존 식단 기록 앱의 이탈 원인은 두 가지입니다.

- **입력 비용** — 음식명 검색·중량 입력·1인분 추정을 매 끼니 요구하면 3일을 넘기기 어렵습니다.
- **동기 부족** — 숫자만 남는 기록은 계속할 이유를 만들어주지 못합니다.

이 앱은 기본 경로를 사진 한 장으로 줄이고, 정확도를 원하는 사용자만 부가 정보를 선택 입력하게 합니다.  
그리고 기록을 식물 성장으로 환산해 지속 동기를 만듭니다.

## 주요 기능

### 식단 기록
사진 → AI 분석 → 저장, 3탭으로 완료됩니다. 부가 정보는 저장 버튼 하단의 텍스트 링크로 배치해 고급 기능처럼 드러내지 않습니다.

### 부가 정보 보정
단백질 종류·소스·조리법·탄수화물·식사 구분·상황 6개 항목을 칩 또는 직접 입력으로 지정하면 보정 계수로 환산되어 칼로리가 실시간으로 갱신됩니다. 그릇과 채움 정도로 분량 오차도 줄입니다.

### 그릇 관리
자주 쓰는 그릇을 이름·용량·재질·형태와 함께 등록하고, 기본 그릇을 지정해 기록 시 자동 선택됩니다. 추가·수정·삭제를 한 화면에서 처리합니다.

### 식물 성장
성공/실패 이진법 대신 **3축 균형** 모델을 씁니다.

| 축 | 연결 기록 |
| --- | --- |
| 물 | 식단 기록 |
| 햇빛 | 운동 기록 |
| 영양 | 수면 · 물 기록 |

한쪽만 챙기면 불균형하게 자라고, 관리 패턴에 따라 다른 품종으로 분화합니다.  
기록을 쉬어도 식물이 죽지 않고 시들었다가 회복되며, 실패를 지적하는 문구와 비주얼은 쓰지 않습니다.  
베이스 18종 × 색상 변이로 총 33종, 일반·희귀·전설 3티어와 시즌 한정 식물이 있습니다.

### 오늘의 미션
물·운동·식단·체중·균형 5개 카테고리에서 매일 3~5개가 자동 선정됩니다. 진행도는 실제 기록 값에서 자동 계산되며 사용자가 체크할 필요가 없습니다.

### 리포트
주간/월간 칼로리 추이, 목표선이 함께 표시되는 체중 변화 그래프, 자주 먹은 음식·자주 쓴 그릇·부족한 영양소 패턴 분석을 제공합니다.

### 친구 · 챌린지
초대 코드로 친구를 추가하고, 챌린지를 직접 만들어(목표·기간 숫자 입력, 공개 여부, 보상) 순위를 겨룹니다. 친구 정원에 하루 3회까지 물을 줄 수 있고 양쪽 모두 EXP를 받습니다.

## 화면 구성 (27)

- **진입 3** — 로그인(Google · Apple), 계정 연결, 온보딩 3단계
- **홈 7** — 홈, 오늘의 미션, 알림, 영양소 상세, 식단 추천, 나의 식물, 식물 도감
- **기록 9** — 기록 탭, 식단 기록, 부가 정보, 기록 상세, 기록 수정, 운동, 체중, 물, 그릇 관리
- **리포트 1** — 주간/월간 리포트
- **소셜 3** — 친구, 친구 & 챌린지, 챌린지 만들기
- **마이 4** — 마이, 내 정보 수정, 알림 설정, 데이터 · 개인정보

하단 탭 5개(홈 · 기록 · 리포트 · 친구 · 마이)와 위치를 옮길 수 있는 플로팅 버튼(빠른 기록)이 최상위 내비게이션입니다.

## 실행 방법

HTML 파일을 브라우저로 열면 로그인 화면부터 클릭으로 이동할 수 있습니다. 빌드나 설치 과정은 없습니다.

- **이후** — 수면 기록 화면, 시즌 식물 확장(40~60종), 꾸미기 아이템, 친구 정원 방문 확장
